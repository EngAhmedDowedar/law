## 📋 وصف المشروع

موقع إلكتروني متكامل لمكتب محاماة، مبني بـ HTML5 وCSS3 وJavaScript خالص مع Bootstrap 5، يتميز بتصميم فاخر بألوان الأسود والذهبي، ودعم كامل للغة العربية واتجاه RTL.

## ✨ المميزات

- تصميم متجاوب يعمل على جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- دعم كامل لاتجاه RTL واللغة العربية
- انيميشن سلس عبر مكتبة AOS
- مؤشر تقدم القراءة
- مؤشر ماوس مخصص (للأجهزة غير اللمسية)
- نموذج تواصل يُرسل عبر واتساب مباشرةً
- تحسينات SEO كاملة (Schema Markup، Open Graph، Twitter Card)
- أقسام: الرئيسية، عن المستشار، لماذا نحن، التخصصات، الأرشيف، آراء العملاء، الأسئلة الشائعة، التواصل
- إمكانية الوصول (Accessibility): skip link، aria-labels، focus-visible
- دعم `prefers-reduced-motion` لتقليل الحركة
- صفحة 404 مخصصة

## ⚙️ التخصيص

### 1. تغيير رقم الهاتف / واتساب
افتح `js/main.js` وغيّر:
```js
const WHATSAPP_NUMBER = "201007929693";
```
ثم ابحث في `index.html` عن `201007929693` واستبدله برقمك.

### 2. تغيير صورة الهيرو
في `index.html`، ابحث عن:
```html
<img src="https://images.unsplash.com/photo-1507003211169-0a1dd7228f2d..."
```
واستبدل الرابط بصورتك الشخصية.

### 3. تغيير الألوان
في `css/style.css`، في قسم `:root`، عدّل المتغيرات:
```css
:root {
    --gold: #D4AF37;      /* اللون الذهبي */
    --black: #080808;     /* اللون الأسود */
}
```

### 4. تغيير اسم المكتب
ابحث عن "الحسين دويدار" في `index.html` واستبدله بالاسم المطلوب.

### 5. تحديث Schema Markup
في `index.html`، في القسم `<script type="application/ld+json">`, حدّث:
- `"name"`: اسم المكتب
- `"telephone"`: رقم الهاتف
- `"url"` و `"@id"`: رابط الموقع
- `"address"`: العنوان
